# Stant — правила работы с проектом

## Главное правило
Всё, что относится к проекту, сохраняется в этот репозиторий и пушится:
- **Код** — в корне проекта / в папках приложения.
- **APK-файлы** — в `apk/` (имя: `stant-<версия>-<дата>.apk`, например `stant-0.1.0-2026-11-22.apk`).
  Лимит GitHub — 100 МБ на файл; если APK больше, нужно перейти на Git LFS или GitHub Releases.
- **Скиллы Claude** — в `.claude/skills/<имя-скилла>/SKILL.md`.
- **Идеи, заметки, планы** — в `docs/ideas/` (по файлу на тему, Markdown).
- **Прочая документация** (решения, архитектура, инструкции сборки) — в `docs/`.

Сессия работает в облачном контейнере, который удаляется — всё, что не закоммичено и не запушено, пропадёт.
Поэтому после каждого значимого шага: `git add` → `git commit` → `git push`.
