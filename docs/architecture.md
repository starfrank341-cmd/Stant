# Архитектура STANT

Игра написана на JavaScript (Three.js r170), упакована esbuild в один файл `game.js`
и запускается внутри Android WebView (`android/`). Внешних ресурсов нет — текстуры и звуки генерируются кодом.

## Модули (`game/src`)
| Файл | Назначение |
|---|---|
| `main.js` | Точка входа: загрузка, игровой цикл, камера, режимы (меню/игра/пауза/гараж), падения, эффекты, динамическое разрешение |
| `world.js` | Карта: рельеф (аналитическая функция высоты), дороги, все районы и рампы, сетка объектов, `groundAt()` для физики |
| `geo.js` | Построитель объединённой геометрии (один меш на материал) |
| `textures.js` | Процедурные текстуры на canvas |
| `env.js` | Небо (шейдер), свет, туман, карта окружения, слежение тени |
| `bike.js` | Модель питбайка и райдера (IK для рук и ног), позы трюков, данные байков, улучшений и покраски |
| `player.js` | Физика байка: двигатель, руление, вилли/стоппи, отрыв по кривизне, полёт, вращения, посадка, падения |
| `tricks.js` | Распознавание трюков, комбо, начисление монет, задания |
| `traffic.js` | Машины (маршруты по кольцам дорог) и люди (пешеходы, зрители) на InstancedMesh |
| `props.js` | Деревья, пальмы, фонари, монеты |
| `fx.js` | Частицы (пул) и следы шин |
| `audio.js` | Синтез звука WebAudio: мотор с передачами, ветер, удары, монеты |
| `input.js` | Мультитач (плавающий стик + кнопки) и клавиатура |
| `ui.js` | DOM-интерфейс: меню, гараж, карта, задания, настройки, HUD |
| `minimap.js` | Миникарта и большая карта с телепортом |
| `save.js` | Сохранение в localStorage |

## Физика
- Фиксированный шаг 240 Гц, гравитация 14 м/с² (полёты чуть дольше — красивее).
- Поверхность — функция `world.groundAt(x,z)`: рельеф + призмы (рампы, здания, контейнеры) + цилиндры (деревья, столбы) + машины.
- Стена = резкий подъём высоты перед колесом. Отрыв = выпуклый перелом (v²·k > g) или падение земли быстрее баллистики.
- Посадка проверяет угол байка к склону, направление и силу удара (зависит от подвески).

## Сборка
```
cd game && npm ci && npm run build      # dist/ и android/app/src/main/assets/www
cd android && gradle assembleRelease     # нужен Android SDK (собирается в GitHub Actions)
```
Версия APK — `android/version.properties`. Ключ подписи `android/keystore/stant.jks` хранится в репозитории
специально, чтобы новые версии ставились поверх старых без потери прогресса.

## Отладка
В браузере: `cd game/dist && python3 -m http.server`, управление с клавиатуры (см. controls.md).
`window.__test.step(n)` — пошаговая симуляция без рендера, `window.game` — доступ к состоянию.
